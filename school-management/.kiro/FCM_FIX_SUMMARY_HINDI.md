### 2. **lib/firebase-web-push.ts** (मुख्य बदलाव)

#### पहले (CDN approach):
```typescript
// ❌ CDN से dynamically load करता था
await loadScript('https://www.gstatic.com/firebasejs/10.14.1/firebase-app-compat.js');
await loadScript('https://www.gstatic.com/firebasejs/10.14.1/firebase-messaging-compat.js');
const messaging = window.firebase.messaging();
```

#### अब (npm approach):
```typescript
// ✅ npm package से import (build time पर bundled)
import { initializeApp, getApps, getApp } from 'firebase/app';
import { getMessaging, getToken, onMessage, isSupported } from 'firebase/messaging';

// Modern modular SDK
const app = getApps().length ? getApp() : initializeApp(FIREBASE_WEB_CONFIG);
const messaging = getMessaging(app);
const token = await getToken(messaging, { vapidKey, serviceWorkerRegistration });
```

**फायदे**:
- ✅ CDN dependency नहीं (CORS free)
- ✅ Tree-shaking friendly (smaller bundle size)
- ✅ TypeScript types built-in
- ✅ Modern async/await syntax
- ✅ Better error messages

### 3. **scripts/generate-firebase-sw.js** (Service Worker generation)

#### पहले:
```javascript
// ❌ अगर CDN fail हो तो service worker completely fail
importScripts('https://www.gstatic.com/.../firebase-app-compat.js');
importScripts('https://www.gstatic.com/.../firebase-messaging-compat.js');
```

#### अब:
```javascript
// ✅ Try-catch के साथ graceful fallback
let firebaseLoaded = false;
try {
  importScripts('https://www.gstatic.com/.../firebase-app-compat.js');
  importScripts('https://www.gstatic.com/.../firebase-messaging-compat.js');
  firebaseLoaded = true;
} catch (e) {
  console.error('CDN import failed, Firebase messaging disabled in service worker:', e);
}

// ✅ सिर्फ तभी initialize करे जब loaded हो
if (firebaseLoaded && FIREBASE_WEB_CONFIG.apiKey) {
  // ... initialization
} else {
  console.warn('Firebase SDK not loaded - background notifications disabled');
}
```

**फायदे**:
- ✅ Service Worker registration fail नहीं होगा
- ✅ Foreground notifications तो काम करेंगे (main app bundled है)
- ✅ Background notifications gracefully disable (better UX)
